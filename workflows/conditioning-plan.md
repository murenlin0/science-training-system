# GPP／體能

力量計劃（GPP 只是一塊）→ `design-plan.md`。只問原理 → `consult.md`。讀 `literature/gpp.md`。

1. **三軸**（未答用預設，輸出必須註明）：定位檔維持型／器械 T1 商健／落位混合。
2. 預設至少心肺 + 工作容量。增強式（跳箱、藥球拋）不是 GPP，歸主項課。
3. 有氧強度：`core/karvonen.py`。禁止 220−年齡。沒心率帶用 RPE／說話測試並註明。
4. 已有力量週期：GPP 掛在剩餘預算。純體能：4–8 周，每周負荷增幅約 ≤10%（NSCA 啟發式）。
5. **主項不動。** 超預算先砍 GPP。發展性 GPP 不進衝刺／測試周。
6. 時序：分天 > 同天間隔 ≥6 h > 同節抗阻在前。下肢主導有氧距深蹲／硬拉 ≥48 h（L2）。

輸出：三軸、各維處方（手段／頻率／時長／%HRR＋目標心率）、與主項時序、何時降檔。
